1. Executive Summary

This report evaluates the latency and throughput trade-offs of offloading AES-128 cryptographic workloads to an FPGA coprocessor via AXI DMA on the Zynq-7000 SoC. A custom direct-register C driver—operating directly at the hardware register level without HAL abstractions—is benchmarked against the official Xilinx Standalone BSP driver. Measurements span payload sizes from 16 Bytes to 8 Kilobytes, evaluated over N = 200 bare-metal iterations on physical silicon:

  • Driver Arming Overhead: The custom direct-register driver achieves a 2.32× reduction in CPU arming latency (1.529 μs vs. 3.540 μs) compared to the Xilinx Standalone BSP by performing direct MMIO register writes and eliminating multi-layer validation overhead.
  • Small-Payload Latency: For single-block (16-byte) transfers, end-to-end transaction latency is reduced from 5.862 μs to 4.675 μs (saving 1.187 μs per transfer).
  • Sustained Bulk Throughput: For large streaming payloads (≥ 4 KB), the pipeline reaches 1.71 Gbps sustained throughput. At bulk sizes, software driver overhead amortizes to <0.3%, and overall throughput becomes strictly bound by HP0 AXI memory-interconnect arbitration.

3.1 Methodology & Measurement Details

Measurement Protocol: Timings were captured on bare-metal execution using Xilinx XTime_GetTime(), reading the ARM Cortex-A9 Global Timer (325 MHz), bounded by dsb sy / isb memory barriers to ensure execution order across measurement checkpoints. Each data point represents the arithmetic mean across N = 200 consecutive runs.

Granularity: The Global Timer provides a resolution of ~3.07 ns per tick (325 MHz). Profiling focuses on isolating software dispatch overhead from hardware interconnect and core processing phases.

3.4 Theoretical vs. Physical Bus Ceilings

  1. AES IP Pipeline Silicon Ceiling: 128-bit @ 75.0 MHz = 9.600 Gbps (1,200 MB/s; pipeline latency 21 cycles ≈ 280 ns).
  2. AXI HP0 Memory Bus Physical Ceiling: 64-bit @ 75.0 MHz = 4.800 Gbps (600 MB/s).
  3. Measured Peak Sustainable Rate: 1.71 Gbps (213.4 MB/s) — includes bidirectional round-trip traffic across the shared HP0 DDR port (MM2S read + S2MM write competing for DDR controller arbitration), width conversion, and cache management.
  4. Architectural Conclusion: On this Zynq-7000 SoC configuration, the empirically verified ceiling is 1.71 Gbps sustained, achieving ~71.2% practical bus utilization against the half-duplex shared HP0 arbitration limit (2.40 Gbps bidirectional partition).

4. Key Architectural Insights

4.1 Overhead Scaling Across Payload Sizes

Driver-level register optimization delivers clear relative improvements for small payloads (≤ 256 B), where setup latency constitutes a significant portion of overall execution time. As payload sizes scale beyond 1 KB, physical memory bus transfer time dominates linearly, while CPU arming latency remains constant (~1.53 μs). At 8 KB, both driver implementations converge at ~1.71 Gbps as DDR memory bandwidth becomes the primary constraint.

4.2 Hardware Offload Break-Even Threshold

Comparing hardware DMA offload against software AES on the Cortex-A9 (≈20 cycles/byte ≈ 260 Mbps ceiling)† identifies a break-even threshold around 180–200 Bytes:

  • Below ~200 Bytes: Software CPU execution is faster because fixed DDR DMA setup, cache maintenance, and AXI handshaking overhead exceed the computation cost.
  • Above ~200 Bytes: Hardware acceleration provides scaling benefits, reaching ~6.6× CPU baseline throughput at 8 KB while offloading the Cortex-A9 core.

† Standard reference baseline for Cortex-A9 software AES implementation.

4.3 Interconnect Arbitration & Bandwidth Efficiency

Sustained throughput plateaus at 1.71 Gbps due to shared HP0 port arbitration: MM2S (read) and S2MM (write) share a single 64-bit AXI HP slave port. This yields an effective 2.40 Gbps theoretical bidirectional split. The achieved 1.71 Gbps corresponds to 71.2% interconnect efficiency, with the remaining margin accounted for by DDR row turnarounds, width converters, and cache operations.

5. Architectural Recommendations

1. Low-Latency MMIO Path for Small Payloads (≤ 256 B)
Providing a direct register-mapped AXI-Lite/FIFO interface to the AES core bypasses DDR round-trips and cache maintenance overhead for short cryptographic frames.
2. Coherent Interconnect via AXI ACP
Routing DMA through the Accelerator Coherency Port (ACP) leverages hardware cache-snooping via the ARM SCU, eliminating software cache flush and invalidate overhead.
3. Scatter-Gather Ring Buffers for Continuous Streaming
Implementing Scatter-Gather descriptor queues allows continuous DMA streaming across multiple blocks without requiring per-transfer CPU intervention.
